# Study results

Generated by the harnesses under [`bench/`](../../bench/) and committed, so a
number quoted anywhere in this project can be traced to the run that produced
it. Regenerate with:

```bash
uv run python -m bench --out research/studies/s2
```

Selection rules, metric definitions and falsification conditions are fixed in
[`../evaluation-protocol.md`](../evaluation-protocol.md), which was committed
before any data was collected. Departures from it are recorded in its deviations
table.

| Study | Question | Status |
| --- | --- | --- |
| [`s2`](s2/) | Does securing setup cost developer time? (RQ2) | Run, scripted arm only |

## A caveat that belongs on every figure

Study 2's manual arm is an **idealised** quickstart: the project a developer
ends up with having made no mistakes, done no debugging and re-read nothing. It
is a lower bound on manual effort, so every advantage reported is a conservative
estimate rather than a flattering one.

The protocol names a scripted LLM agent as the intended primary arm. That needs
a model capable of following documentation, and none was available; the human
arm is deferred separately and recorded as such in the protocol.
