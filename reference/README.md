# Reference

Specifications that define how `toolseal` behaves. These are normative: when the
code and a document here disagree, one of them is a bug.

| Document | Defines | Plan step |
| --- | --- | --- |
| [`taxonomy.md`](taxonomy.md) | The configuration misconfiguration taxonomy — what `audit` detects and what `init`/`add` prevent | P1 |

Design rationale and project planning live outside this directory and outside
the repository. This directory holds only what a contributor or reviewer needs
in order to understand or verify the tool's behaviour.
